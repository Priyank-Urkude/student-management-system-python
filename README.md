# student-management-system-python
A Python-based CRUD student management system with Pandas data handling and Matplotlib-based performance visualization.
 Add new student records

Features:
<ul>
<li>Add new student records</li>
<li>View all student data</li>
<li>Visualize a student's marks using a bar graph</li>
<li>Update student marks</li>
<li>Delete student records</li>
<li>Automatically calculate student averages</li>
<li>Automatically assign grades based on average mark</li>
<li>Store student records in a CSV file</li>
<li>Validate marks between 0 and 100</li>
<li>Handle invalid numerical input</li>
</ul>

Technologies Used:
<ul>
<li>Python</li>
<li>Pandas — CSV data handling and DataFrame operations</li>
<li>Matplotlib — student performance visualization</li>
<li>OOP — student data and functionality organized using a Student class</li>
</ul>
